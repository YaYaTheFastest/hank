How you use the vault

Design answer — not a file browser. The vault is the brain; this app is the door.

Bottom line

You never open the vault. You enter by job.

Obsidian stays Hank’s backend. You interact only through four doors on this phone: pressure, stuff, work, and talk. Each domain gets a surface shaped for that job — not a folder tree, not a spiderweb of labels.

1 · Pick a door (try one)

Pressure door

When life is hot: faith, conflict, direction, fatigue. Start from the situation, not the note title.

  1. 1Name the pressure (or pick a card)
  2. 2Get cited truth + one next step
  3. 3Optional: walk a scene, or talk it through with Hank

Talk door

Primary write path. Chat carries intent (query, capture, directive). Photos land in _Cowork Inbox; the loop files them. You never open Obsidian to “put it in the right folder.”

  1. 1Ask or dump the fact in Chat
  2. 2Or Send a photo → Save to Files → _Cowork Inbox
  3. 3Next loop pass files with intent tags

5 · Design rules

Do this

  • Enter by job (pressure / stuff / work / talk)
  • Prefer domain surfaces (Bible Guidance, Equipment cards, Castle)
  • Write through Chat or photo — loop owns the folders
  • Demand cite + one next step
  • Pull when you need it — no bombardment

Don’t do this

  • Open Obsidian to “find the note”
  • Use the network graph as the main way to learn
  • Browse a full-vault file tree on the phone
  • Expect one generic “search everything” to replace domain design
  • Edit vault files yourself for day-to-day truth

6 · System split (why this works)

Vault = source of truth (Grok writes).
HANK app = your front door (this page + modules).
_Cowork Inbox = capture chute (photos, drops).
Chat = intent channel (query · capture · directive).
Loop = 7:00 · 13:00 · 19:00 + queue watcher — files, syncs, deploys.
